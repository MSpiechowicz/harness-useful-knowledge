Platform : Deploy the gateway

Created by Ann, last modified on Oct 01, 2026

Use this runbook to deploy the gateway to production.

Prerequisites

  • Access to the cluster
  • The gwctl tool

Steps

gwctl deploy --env prod
gwctl status
EnvURL
prodhttps://gw.example.com

Rollback

Run gwctl rollback & check the status.
